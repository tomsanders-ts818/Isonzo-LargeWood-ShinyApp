# Instream large wood on the River Isonzo

Interactive Shiny app of large wood and bridge blockage risk on the River Isonzo, with proposed large wood catcher locations. GEOM184 Open Source GIS, Coursework Part A, Task 2 (University of Exeter, 2026).

**Live app:** https://tomsanders-ts818-isonzo-large-wood.share.connect.posit.cloud/ (may take up to a minute to start if idle)

To run locally, open the folder in RStudio and run `app.R`.
